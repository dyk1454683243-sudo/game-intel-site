佩丽卡 perlica

verified card

定位：术师

技能

  • 协议α·突破 basic — 普通攻击：对敌人进行至多4段攻击，造成电磁伤害。作为主控干员时，重击会造成15点失衡。 下落攻击：处于空中时使用普通攻击，会下落并攻击附近敌人，造成电磁伤害。 处决攻击：附近有敌人处于失衡状态时使用普通攻击，将处决该敌人，造成大量电磁伤害并恢复一定技力。
  • 协议ω·雷击 battle — 释放一道电磁能量从空中落下，对小范围内敌人造成电磁伤害并施加电磁附着。
  • 即时协议·闪链 combo — 当主控干员对敌人造成重击后可以发动。 释放积蓄的电磁能量轰击目标，造成电磁伤害并强制施加短暂的导电。
  • 协议ε·70.41κ ultimate — 立即传送一块巨大的轨道漂浮物对目标区域进行毁灭性打击，对区域内的敌人造成大量电磁伤害。
  • 歼灭协议 talent — 1阶描述：对失衡的敌人造成的伤害+20%。 2阶描述：对失衡的敌人造成的伤害+30%。
  • 循环协议 talent — 1阶描述：连携技即时协议·闪链命中处于破防状态的敌人时，还会弹射1次。
  • 监督·α base — 1阶描述：进驻总控中枢时，所有干员心情恢复提升8%
  • 监督·β base — 2阶描述：进驻总控中枢时，所有干员心情恢复提升12%
  • 协议调度·β base — 1阶描述：进驻制造舱时，武器经验素材的生产效率提升20%
  • 协议调度·γ base — 2阶描述：进驻制造舱时，武器经验素材的生产效率提升30%

加点优先级

  • Off Field: Battle Skill >= Ultimate >= Basic Attack > Combo Skill
