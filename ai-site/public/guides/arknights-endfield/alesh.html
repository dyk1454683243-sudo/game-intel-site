定位：先锋

技能

  • 基本挥竿法 basic — 普通攻击：对敌人进行至多5段攻击，造成物理伤害。作为主控干员时，重击会造成17点失衡。 下落攻击：处于空中时使用普通攻击，会下落并攻击附近敌人，造成物理伤害。 处决攻击：附近有敌人处于失衡状态时使用普通攻击，将处决该敌人，造成大量物理伤害并恢复一定技力。
  • 非常规路亚 battle — 勾起冰块砸击面前的敌人，对目标造成物理伤害。命中处于寒冷附着状态的目标时，消耗掉目标身上所有寒冷附着，对其强制施加冻结，并基于消耗层数恢复技力，命中多名目标时仅恢复1次。
  • 凿孔底钓术 combo — 当附近目标的法术异常或源石结晶被消耗时可以发动。 在敌人脚下开洞垂钓，造成物理伤害，并恢复一定技力，有一定概率能钓出珍鳞，大幅增加伤害并额外恢复技力。
  • 大鳞，上钩！ ultimate — 钓起超乎想象的大鳞砸击面前的所有敌人，造成大范围的寒冷伤害，施加寒冷附着并恢复一定技力，每击败一个目标将额外恢复一定技力。
  • 闪冻锁鲜 talent — 1阶描述：附近有敌人被冻结或被附着源石结晶后，自身获得3点终结技能量.自身造成冻结触发上述效果时，额外获得6点终结技能量。该效果每3秒内最多触发一次。 2阶描述：附近有敌人被冻结或被附着源石结晶后，自身获得4点终结技能量。自身造成冻结触发上述效果时，额外获得8点终结技能量。该效果每3秒内最多触发一次。
  • 钓鳞老手 talent — 1阶描述：每10点智识会使连携技凿孔底钓术钓起珍鳞的概率+0.2%，最多+30%。 2阶描述：每10点智识会使连携技凿孔底钓术钓起珍鳞的概率+0.5%，最多+30%。
  • 悠闲垂钓·α base — 1阶描述：进驻总控中枢时，所有干员心情恢复提升8%
  • 悠闲垂钓·β base — 2阶描述：进驻总控中枢时，所有干员心情恢复提升12%
  • 钓友情报网·α base — 1阶描述：进驻会客室时，干员收集到线索1——联盟工团的概率小幅提升（进驻即生效，同类不可叠加）
  • 钓友情报网·β base — 2阶描述：进驻会客室时，干员收集到线索1——联盟工团的概率提升（进驻即生效，同类不可叠加）
