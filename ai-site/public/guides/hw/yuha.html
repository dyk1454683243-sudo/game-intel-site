尤哈 yuha

verified card

定位：T0 / 辅助 / 回AP / 子弹圣女

技能

  • 制式射击 active — 造成射击攻击力60%的穿刺伤害
  • 翻滚 active — 低空跃向指定位置，获得20的行动力。
  • 精神腐蚀 active — 对扇形范围内的敌人施加持续2R的穿刺防御减少180效果。
  • 燃烧的狂信 passive — 生命值在50%以上的队友使用基于<枪械>的技能时，将从珠哈处获得行动恢复力和攻击力增加效果。
  • 执行射手 active — 指定的队友获得100点行动力，并进入持续1轮的【执行射手】状态。
  • 信仰的兄弟姐妹 passive — 半径3米范围内队友的命中率提升40%。

加点优先级

  1. 最优先点加ap的大招和增伤，其次翻滚点到6级可以免费使用，剩下点破甲和增伤。
  2. 制式射击: 不加
  3. 翻滚: 6级即可
  4. 精神腐蚀: 6级即可
  5. 燃烧的狂信: 尽量点满
  6. 执行射手: 尽量点满
  7. 信仰的兄弟姐妹: 不加
